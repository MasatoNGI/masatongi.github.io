MNAIDesk Gmail Push

MNAIDesk Gmail Push is a private, single-user automation operated by the MNAI estate operator for the MNAIDesk Gmail mailbox. It helps the operator notice incoming mail that may require attention.

The app uses the Gmail API’s gmail.readonly scope to detect mailbox changes, read message metadata and text, and classify incoming mail for the operator. Gmail push notifications delivered through Google Cloud Pub/Sub tell the watcher when to check for changes.
