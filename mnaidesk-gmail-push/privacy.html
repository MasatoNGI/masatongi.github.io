Privacy policy — MNAIDesk Gmail Push

Last updated November 22, 2026.

Who operates the app

The MNAI estate operator runs this private, single-user automation for the MNAIDesk Gmail mailbox.

Data accessed and used

The OAuth app uses the Gmail API’s read-only gmail.readonly scope to read the MNAIDesk mailbox identity, message identifiers, history, headers, labels, and message text. The watcher uses message text to classify incoming mail, identify requested actions or deadlines, and produce a screened summary for the operator. It processes plain-text and HTML message body parts in memory. It makes no attachment-download requests and does not use this scope to send, modify, or delete Gmail messages.

Gmail sends change notifications through Google Cloud Pub/Sub. The notifications include the mailbox address and a Gmail history identifier. The watcher uses these notifications to find changes. If the API cannot read a message body, the estate’s separate signed-in Gmail browser watcher can attempt the read while preserving the message’s read state.

Sharing and retention

Google provides Gmail and Pub/Sub for this service. The estate retains operational records and screened summaries under the operator’s control. Selected summaries are sent to the operator’s private message box. The watcher keeps full original message bodies out of its journal and excludes credential values from notices. The operator does not sell Gmail data or use it for advertising or model training. The app’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Access and deletion

OAuth credentials are stored on the operator’s machine with owner-only access. The operator can revoke the app’s access from Google Account connections and remove locally stored records. For privacy or deletion requests, contact mnaidesk@gmail.com.
