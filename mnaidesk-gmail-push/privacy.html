Privacy policy — MNAIDesk Gmail Push

Last updated November 23, 2026.

Who operates the app

The MNAI estate operator runs this private automation. It serves the MNAIDesk mailbox and supports a separately authorized personal Gmail mailbox belonging to the same operator.

Data accessed and used

For each authorized mailbox, the app uses the Gmail API’s read-only gmail.readonly scope to read the mailbox identity, message identifiers, history, headers, labels, and selected message text. The watcher uses text to classify mail, identify requested actions or deadlines, and produce a screened summary. It processes plain-text and HTML message body parts in memory. It makes no attachment-download requests and does not use this scope to send, modify, or delete Gmail messages.

Gmail change notifications contain the mailbox address and a Gmail history identifier. Google Cloud Pub/Sub carries them through a separate topic and subscription for each mailbox. Periodic checks can recover missed changes. For MNAIDesk, a separate signed-in Gmail browser watcher can attempt a body read when the API body read fails, while preserving the message’s read state.

Sharing and retention

On the operator’s machine, the estate retains operational records such as message IDs, headers, classification results, watch and delivery records, and screened summaries. Personal mailbox records and Gmail credentials are kept separately from MNAIDesk records and credentials. The watcher keeps full original message bodies out of its journal and excludes credential values from notices.

Selected MNAIDesk summaries go to the operator’s private message box. When personal notifications are enabled, selected personal summaries are delivered to the operator’s designated private Muse chat. A separate ntfy alert may cue the operator to check that chat when an item calls for the operator personally to act.

The operator does not sell Gmail data or use it for advertising or model training. The app’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Access and deletion

OAuth credentials are stored on the operator’s machine with owner-only access. The operator can revoke the app’s access from Google Account connections and remove locally stored records. For privacy or deletion requests, contact mnaidesk@gmail.com.
